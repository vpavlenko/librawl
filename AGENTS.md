# Git workflow

- After every librawl change, run the relevant checks, commit the changes, and push the commit to the configured upstream branch.

## Measure recoloring

Use the [modulation pickup convention](README.md#modulation-onsets-and-pickups) when authoring mid-measure tonic changes.

Escape cancels the preview, clears the selected measure and blurs its focused measure number. The number remains reachable by Tab.
